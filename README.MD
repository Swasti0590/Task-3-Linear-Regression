# Task 3 - Linear Regression

## Objective

Implement and understand Linear Regression for house price prediction.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset

Housing dataset used for predicting house prices.

## Project Steps

1. Imported required libraries
2. Loaded the Housing dataset
3. Checked dataset shape and columns
4. Checked missing values
5. Preprocessed categorical variables
6. Split data into training and testing sets
7. Trained a Linear Regression model
8. Generated predictions
9. Evaluated the model using MAE, MSE and R²
10. Visualized actual and predicted values
11. Analyzed feature coefficients

## Evaluation Metrics

The model was evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

## Conclusion

Linear Regression was successfully implemented for house price prediction.
The model performance was evaluated using standard regression metrics,
and feature coefficients were analyzed to understand their relationship
with house prices.
